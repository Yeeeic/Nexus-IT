# NEXUS IT

Plataforma de monitoreo y soporte técnico para administrar equipos, alertas y solicitudes desde un solo lugar.

## Funciones principales

- Panel de control para operadores de TI.
- Monitoreo de dispositivos, estado y métricas.
- Inventario de hardware y software.
- Alertas y seguimiento de incidentes.
- Gestión de tickets de soporte y archivos adjuntos.
- Usuarios, organizaciones, permisos y auditoría.
- Agente para equipos Windows.
- Acciones remotas controladas y registradas.
- Tema claro y oscuro.

## Tecnologías

- **Frontend:** React, TypeScript, Vite y Vitest.
- **Backend:** Python, FastAPI, SQLAlchemy y Pydantic.
- **Datos:** PostgreSQL, Redis, Alembic y SQLite.
- **Infraestructura:** Docker Compose y NGINX.
- **Agente Windows:** Python, PyInstaller y Windows Services.
- **Seguridad:** sesiones protegidas, permisos por rol, aislamiento por organización y firma Ed25519.

## Estado

Proyecto en desarrollo. Incluye pruebas automatizadas y documentación del sistema.

Las vistas de pantalla remota y terminal son demostraciones visuales. No controlan equipos ni ejecutan comandos libres.
